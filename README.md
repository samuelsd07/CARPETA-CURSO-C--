# Bootcamp Programacion de Cero a POO

## Descripción
Este repositorio corresponde al bootcamp *Programacion de Cero a POO*, un curso virtual en vivo orientado a estudiantes que estan iniciando en programacion y desean construir una base solida antes de avanzar hacia la Programacion Orientada a Objetos.

El enfoque del bootcamp sigue una progresion academica practica:
*logica de programacion - diagramas - pseudocodigo - C++ estructurado - Java POO*
## Objetivos del respositorio
Este repositorio tiene como finalizada organizar y almacenar el materia, ejercicios, practicas y proyectos desarrollados durante el curso, ademas de servir como evidencia del proceso de aprendizaje mediante el uso de Git y Github.

## Contenido del curso 
 - logica y resolucion de problemas
 - diagramas de flujo
 - pseucodigo en PSeint
 - introduccion a C++
 - variables, operadores y entrada/salida
 - estructuras repetitivas
 - arreglos
 - funciones y modularizacion
 - introduccion a Git y Github
 - preparacion del mini proyecto 
 - introduccion a Java
 - conceptos basicos de POO
## Estructura del repositorio 
 La estructura puede variar segun el avance del curso, pero en generar el repositorio tiene las carpetas dividas por clases:
  - clase 4/  material de la clase 4
  - clase 5/  material de la clase 5
  - clase 6/  material de la clase 6
  - clase 7/  material de la clase 7
## Metodologia de trabajo 
Durante el bootcamp se promueve un flujo de trabajo ordenado.
    - desarrollar ejercicios y proyectos de forma progresiva
    - registrar avances mediante commits
    - publicar cambios en github
    - mantener una estructura en nuestro repositorio 
    - documentar de forma basica los proyectos mediante un readme
