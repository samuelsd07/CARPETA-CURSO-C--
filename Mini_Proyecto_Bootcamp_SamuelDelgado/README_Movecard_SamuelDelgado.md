Nombre Mini Proyecto: Movecard

## Resumen:
Movecard es una tarjeta para pago de transporte público el cual cuenta con los servicios de registro de tarjetas, búsqueda, ingreso de saldo, y un recargo de bonificación. Este sistema está pensado para ser diseñado como una app y que el usuario pueda manejar como una especie de Banca Móvil.

## Objetivo:
El objetivo de MoveCard es que la experiencia de pago del usuario al momento de usar transporte público se vuelva más rápida y mejor organizada, además que sería clave para otorgar seguridad para el usuario y el conductor al momento de no tener que manejar dinero físico en un sector que es considerado peligroso.
